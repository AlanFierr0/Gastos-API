# Concept Mapping Examples

Use these examples as reference to map transactions to existing concepts. These are common patterns in the database.

## Mapping Rules

When you see a transaction that matches any of these patterns, use the corresponding existing concept from the database. Look for partial matches (e.g., "JUMBO" should map to "Supermercado", "EDENOR" should map to "Luz", etc.).
